Teks tema ditulis langsung dalam Bahasa Indonesia dan dibungkus fungsi terjemahan (`__()`, `esc_html_e()`, dll.) dengan text domain `yumnia`.
Untuk versi Bahasa Inggris nanti: buat `yumnia.pot` dengan `wp i18n make-pot . languages/yumnia.pot`, terjemahkan ke `en_US.po/.mo`, lalu pasang plugin multibahasa (mis. Polylang) untuk konten.
